
S-52 图标的全球显示库为 `Preslib_e4.0.0.dai`，这个格式是纯文本文件，但内部有特殊的格式和分隔符。PresLib 用于定义点符号、复杂线型和填充图案的语言，使用虚拟的“画笔”在屏幕区域上绘制图形，画布上的位置用二维笛卡尔坐标 (x, y) 表示。

## 基本格式

- 记录间以一行 `****    0` 分隔
- 文本之间的分隔符为 `\x1f`，这个字符是单元分隔符 (Unit Separator)，是一个隐藏的 ASCII 控制字符，正常在文本编辑器里就是显示不出来的，在 VSCode 里会红色高亮显示。

## 颜色表

Preslib 的第一段为标题，第二/三/四段分别为 DAY / DUSK / NIGHT 颜色表。

```
****    0
0001    500002
COLS   14CS00002NILDAY

...

CCIE   31RADLO0.31000.560020.00green
CCIE   30AIOBL0.18000.150022.00blue
****    0
```

- 0001：索引
- COLS：声明配色类型（DAY/DUSK/NIGHT）
- CCIE ：颜色令牌及 CIE xyY 色值

### CIE xyY 色彩空间

CIE xyY 是一种颜色空间，将颜色的**亮度**和**色度**分开，方便在二维平面上表示颜色。
xyY 的 x 和 y 代表颜色的色度坐标（在平面图上的位置），Y 代表明度（颜色的亮度）

- x 值：色度坐标，表示颜色偏红的比例
- y 值：色度坐标，表示颜色偏绿的比例（结合 x 能确定具体色相和饱和度）
- Y 值：明度，通常数值越大代表越亮

在上述 Preslib 的示例中最后一行，CCIE 为段长，30AIOBL 为令牌，0.1800 为色值 x，0.1500 为色值 y，22.00 为亮度 L，颜色名为 blue

CIE xyY 转为绘制 svg 的十六进制颜色需要经过转 XYZ，转线性RGB，Gamma校正，转 HEX 的过程，上面的例子转为十六进制是 `#007AFF`

## 查找表的符号/线型/图案定义

```
****    0
0001    500005
LUPT   40LU00005NILnodataA00000SPLAIN_BOUNDARIES
ATTC    1
INST   23AC(NODTA);AP(NODATA03)
DISC   12DISPLAYBASE
LUCM    611050
****    0
```

SYMB（点）、LNST（线）、PATT（面），分别由元数据行、颜色引用行、矢量指令行组成

- 0001：索引
- LUPT：查找表条目标识字段
	-  `40`：后面紧跟的字符串总长度为 40 个字符
	- `LU00005`：Lookup Table 内部索引
	- `NIL`：表示**没有属性限制**（对所有 nodata 类型的物标通用）
	- `nodata`：物标类 Object Class，代表无数据区域或未测量区域
	- `A`：代表该物标是一个 **面状物标（Area）**
	- `00000`：图层或特殊标志位
	- `S`：代表 Simplified 或特定显示子类
	- `PLAIN_BOUNDARIES`：表明此规则适用于船员选择简单边界（Plain Boundaries）时的海图显示模式（S-52 允许在“简单边界”和“符号化边界”之间切换）
- ATTC：属性组合限制条件 / Attribute Combination，对应 LUPT 的 NIL，只要物标类型是 `nodata` 就直接应用
- INST：记录渲染指令，渲染指令在下面说明
- DISC：描述分类 / Display Category，`12DISPLAYBASE` 里 12 表示字符串长度，DISPLAYBASE 表示基础显示级别
- LUCM：视图组与优先级，6 为字符串长度，11050 是视图组代码

### 渲染指令

| 指令                      | 描述                                               |
| ----------------------- | ------------------------------------------------ |
| SY(symnam)              | 绘制名为 symnam 的点符号                                 |
| SY(symnam, orient)      | 绘制名为 symnam 的点符号，角度或属性为 orient                   |
| LS(style, width, color) | 绘制标准线型，参数为线形 / 线宽 / 颜色                           |
| LC(lcnam)               | 绘制符号化线形 lcnam                                    |
| AC(colname)             | 填充区域颜色为 colname                                  |
| AP(patname)             | 平铺矢量图案为 patname                                  |
| TX(text_spec, ...)      | 显示文字                                             |
| TE(text_spec, ...)      | 显示文字，格式化                                         |
| CS(procnam)             | 条件符号化，`procnam` 是 S-52 标准规定的标准算法函数名，由 ECDIS 引擎实现 |

## 矢量符号定义

对于点线面，符号条目标识和颜色引用字段的名字不同

下列文本范例表示了具体符号的绘画规范和绘画过程

```
****    0
0001    501612
SYMB   10SY01612NIL
SYMD   39CHINFO10V026350185900495004950240001605
SXPO   32manufacturer's information note
SCRF    6AADINF
SVCT   69SPA;SW1;PU2400,2100;PD2895,2100;PD2895,1605;PD2400,1605;PD2400,2100;
SVCT   33SPA;SW1;PU2631,1672;PD2631,1714;
SVCT   45SPA;SW1;PU2635,2009;PD2635,1775;PD2543,1774;
SVCT   33SPA;SW1;PU2544,2010;PD2711,2010;
****    0
```

- SYMB：点符号条目标识，`10SY01612` 是索引，`NIL` 是没有后缀
- SYMD：符号定义核心参数
	- `39`：后面字符串长度为 39。
	- `CHINFO10`：符号的英文名称。
	- `V`：代表 Vector（矢量符号）（S-52 符号分为矢量型 V 和位图型 B）
	- 后续数字代表该符号的中心点坐标（Pivot Point）、包围盒宽度与高度（Bounding Box）等空间参数（单位通常是 0.01 毫米）。例如指定了符号的中心在 `(2635, 1859)`，宽高为 `495 x 495`
- SXPO：符号描述
- SCRF：颜色引用
- SVCT：矢量绘图指令

### 点 / 线 / 面的符号条目标识

| 符号条目标识           | SYMB（点） | LNST（线） | PATT（面） |
| ---------------- | ------- | ------- | ------- |
| 元数据              | SYMD    | LIND    | PATD    |
| 颜色引用（通过颜色引用查颜色表） | SCRF    | LCRF    | PCRF    |
| 矢量绘图指令           | SVCT    | LVCT    | PVCT    |

### 矢量绘图指令

| **指令** | **含义** | **说明**                          |
| ------ | ------ | ------------------------------- |
| SP     | 设置颜色   | 后接令牌变量号，经 SCRF/PCRF/LCRF 映射到颜色表 |
| SW     | 设置线宽   | 值 × 0.3                         |
| ST     | 设置透明度  | 0/1/2/3 → 100%/75%/50%/25%      |
| PU     | 抬笔移动   | 设定下一段起点                         |
| PD     | 落笔绘制   | 给出坐标序列；空坐标表示画点(圆)               |
| PM     | 路径模式   | 0=开始子路径, 1=继续, 2=结束             |
| CI     | 绘制圆    | 以最后 PU 点为圆心                     |
| FP     | 填充多边形  | 对当前闭合路径填色                       |
| EP     | 描边多边形  | 对当前闭合路径描边                       |
| SC     | 引用子符号  | SC(符号名,方向)，方向仅 0/1/2            |

```
SVCT 69SPA;SW1;PU2400,2100;PD2895,2100;PD2895,1605;PD2400,1605;PD2400,2100;
```

该范例意思是选择刚才的 SCRF 定义的颜色，选择线宽为 1，抬笔移动到坐标 (2400, 2100)，落笔从当前位置画一条线到 (2895, 2100)，画线到(2895, 1605)，画线到 (2400, 2100)，实际上就是绘制一个矩形。
