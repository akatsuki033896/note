### 报警类型

枚举报警类型的追加放在 `ALARM_NUM` 前即可。`ALARM_NUM` 是计哨兵，用做数组长度和循环边界，放在它后面的枚举值等于被完全排除。

```cpp
// xnAlarm.h
//新加报警，xnDefaultSettings.xml文件里要设置默认优先级; 报类型项不能删除，新增报警类型只能加往后追加
typedef enum 
{
    AIS_MEETING_ALARM = 0,		//AIS会遇报警;
    ...
    UKC_ALARM,                  //富余水深报警；
    LAYER_ALARM,                //图层报警
    ALARM_NUM,
} xnAlarmType;
```

### 报警附加参数 `tagParam`

之后可能追加新的参数。以添加新的报警类型 `LAYER_ALARM` 为例

```cpp
// xnAlarm.h
class xnAlarmInfo {
	union
    {
        xnCpaInfo cpaInfo;			//会遇报警参数;
        double	contourVal;			//等深线值;
        xnRefDatum refDatum;		//参考基准;
        double	xtdVal;				//偏航报警距离;
        int keyId;					//监控点Id;
        int aisCount;				//ais总数;
        double dstnToDestination;	//距离目的地的距离;
        double draggingDstn;		//走锚距离;
        double navtexFreq;			//航行警告频率;
        int safetyNetMsgCode;		//安全网消息码;
        int radarCapacityType;		// 0即将满 1已满;
        double ukcLimit;            //富余水深限制
    } tagParam;	                    //报警附加参数;
};
```

修改完 `tagParam` 后处理报警参数字符串

```cpp
// xnAlarm.cpp
QString xnAlarmInfo::TagParamToString(void) const;
```

数组的数据可参照 `xnAlert` 结构体

```cpp
struct xnAlert
{
    QString title;	      //标题 最大16字符;
    QString description;  //完整描述;
    char	priority;	  //E紧急报警 A报警 W警告 C注意;
    char    category;	  // A B C;
    int		identifier;	  //10000-9999999保留;
    xnAlert();
    xnAlert(QString title, QString description, char priority, char category, int identifier);
};
```
