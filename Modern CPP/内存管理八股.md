# `malloc()` 和 `new` 的区别

| `new`                | `malloc`        |
| -------------------- | --------------- |
| 根据类型自动计算需要的内存大小      | 手动计算大小          |
| 返回对象类型指针             | 返回 `void` 指针    |
| 自动调用对象构造函数初始化        | 不初始化            |
| 异常机制检测内存分配失效         | 内存分配失败返回 `NULL` |
| 可以重载，和自定义构造 / 析构函数配合 | -               |
```cpp
#include <iostream>
#include <cstdlib>

int main() {
    // 使用new进行动态内存分配和释放
    int* newPtr = new int(10);
    std::cout << "Value allocated with new: " << *newPtr << std::endl;
    delete newPtr;

    // 使用malloc进行内存分配和释放
    int* mallocPtr = (int*)malloc(sizeof(int));
    if (mallocPtr != nullptr) {
        *mallocPtr = 20;
        std::cout << "Value allocated with malloc: " << *mallocPtr << std::endl;
        free(mallocPtr);
    }

    return 0;
}
```

# 野指针和空悬指针

## 野指针

**没初始化的指针**，指向随机 / 未知 / 不确定地址，解引用可能导致程序崩溃

```cpp
int main() {
    int* ptr; // 未初始化的指针，成为野指针
    // 使用野指针会导致未定义的行为
    *ptr = 5; // 解引用野指针，可能导致程序崩溃
    return 0;
}
```

## 空悬指针

指针最初指向的内存已经被释放，但指针的值没有被清零，**对悬空指针操作的结果不可预知**

```cpp
int* createInt() {
    int value = 5;
    int* ptr = &value;
    return ptr; // 返回指向局部变量的指针
}

int main() {
    int* danglingPtr = createInt(); // 指向已释放的内存

    // 对悬挂指针操作的结果不可预知
    int value = *danglingPtr; // 解引用悬挂指针，可能导致未定义的行为

    return 0;
}
```

# `NULL` 和 `nullptr`

| `NULL`    | `nullptr` |
| --------- | --------- |
| 整数值0      | 关键字，表示空指针 |
|           | 更安全       |
| 用于整数类型上下文 | 用于指针类型上下文 |

# 引用和指针的区别

| 指针                   | 引用             |
| -------------------- | -------------- |
| 保存另一个变量的内存地址         | 和原变量共享内存地址     |
| 除了指针常量，可以被重新赋值指向不同变量 | 必须初始化，初始化后不许更改 |
| 可以为 `nullptr`        | 必须绑定到一个变量      |
| 需要解引用以获取 / 修改指向的值    | 直接用，不用解引用      |

```cpp
#include <iostream>

int main() {
    int a = 10;
    int b = 20;

    // 指针
    int *p = &a;
    std::cout << "Pointer value: " << *p << std::endl; // 输出：Pointer value: 10

    p = &b;
    std::cout << "Pointer value: " << *p << std::endl; // 输出：Pointer value: 20

    // 引用
    int &r = a;
    std::cout << "Reference value: " << r << std::endl; // 输出：Reference value: 10

    // r = &b; // 错误：引用不能被重新绑定
    int &r2 = b;
    r = r2; // 将 b 的值赋给 a，r 仍然引用 a
    std::cout << "Reference value: " << r << std::endl; // 输出：Reference value: 20

    return 0;
}
```

- 引用没有顶层const即`int & const`，因为引用本身就不可变，所以在加顶层const也没有意义； 但是可以有底层const即 `const int&`，这表示引用所引用的对象本身是常量
- 指针既有顶层const(`int * const`--指针本身不可变)，也有底层const(`const int *`--指针所指向的对象不可变)
- `sizeof(指针)` 返回指针变量本身大小 (64bit为8字节，32bit为4字节)
- `sizeof(引用)` 返回被引用对象本身的大小
